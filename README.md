# Readme placeholder for the Bierman Inc website project.

This project contains a modern multi-page website for Bierman Inc with a New Holland Blue design system.

Files included:
- index.html
- about.html
- products.html
- trade-shows.html
- contact.html
- styles.css
- script.js

Preview locally:
1. Open the project directory in a browser, or
2. Run: python -m http.server 8000
3. Visit: http://localhost:8000

This design keeps each section on its own page and includes a dedicated products page with small product cards.
